AVALON

Minecraft-inspired party game · versi web lokal

⚔️ Buat permainan

Main bergiliran pada satu perangkat (pass-and-play). Masukkan nama pemain, lalu setiap pemain melihat perannya secara pribadi.

Aturan singkat
  • Raja memilih tim misi; semua pemain memberi suara setuju/tolak.
  • Jika tim disetujui, anggota tim memilih berhasil atau sabotase. Peran baik hanya boleh berhasil.
  • 3 misi berhasil membuat kubu baik menang, kecuali Assassin menebak Merlin dengan benar.
  • 3 misi gagal membuat kubu jahat menang. Ronde ke-4 membutuhkan 2 sabotase untuk gagal.
  • Setelah 5 penolakan tim berturut-turut, kubu jahat menang.
